Paramètres
    
    

      
Accès internet?Ajoute les outils web_search / web_open / web_read / web_grep, avec le moteur web intégré : aucune installation. Il lit les pages servies en HTML, sans exécuter leur JavaScript. Actifs seulement si le mode agent est actif.

      

        
      

    

    

      
Contrôle du navigateur?Donne à l'IA le contrôle d'un navigateur sur cette machine (outils browser_open / browser_click / browser_type / browser_key / browser_scroll). L'IA lit les éléments numérotés de la page et agit par numéro — aucune vision requise, ça marche avec de petits modèles. browser_screenshot s'ajoute si la vision est active. Nécessite Chrome/Chromium/Edge installé. Actif seulement si le mode agent est actif.

      

        
      

    

    

      
MCP servers?Connecte des serveurs MCP (Model Context Protocol) pour donner de nouveaux outils à l'IA : accès fichiers, bases de données, APIs métier… stdio = programme lancé localement (npx/uvx/binaire) · http = serveur distant. ⚠ un serveur stdio exécute du code sur cette machine, au même titre que le shell.

      

        
        
        
        
        

          
Aucun serveur. Un serveur MCP ajoute des outils : fichiers, base de données, API…

        

        
      

    

    

      
Dictée vocale?Le bouton micro du composeur enregistre la voix et l'envoie à une API de transcription compatible OpenAI (/audio/transcriptions). Par défaut : Whisper chez Groq, clé à créer sur console.groq.com. Un serveur Whisper local fonctionne aussi. Sans clé, la dictée intégrée au navigateur est utilisée.

compacter au plus tard à?Par défaut, le contexte est compacté à 75 % de la fenêtre du modèle. Avec une très grande fenêtre, ce seuil n'est presque jamais atteint et les longues conversations deviennent lentes. Un plafond compacte plus tôt, quelle que soit la fenêtre.
